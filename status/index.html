How This Board Updates

The board is a static page over a generated JSON file. To refresh the data, build and run the .oo driver (dogfood law — no shell): 

export OODA_COMPILER=/Projects/openOODA-core/oodac/bin/oodac.real
export OODA_NO_JAIL=1 OO_LIST_AMBIENT_QUOTA=8589934592
$OODA_COMPILER build -o /tmp/quota-refresh src/quota_refresh.oo
OODA_FLEET_HOME=$HOME OODA_FLEET_XDG=$XDG_RUNTIME_DIR \
  /tmp/quota-refresh status/quota.json

The site is static — publishing a refresh means committing the regenerated status/quota.json and pushing to GitHub.
