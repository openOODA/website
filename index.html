Fail-Closed by Design_

openOODA is a capability-secure systems language where every effect requires an explicit, unforgeable capability token. Your process is born with no privileges. That is not an accident. That is the type system. A function that communicates over the network takes &NetCap or it does not compile. E_CAP is not a warning. Hardware first, IEEE 754 precision, zero ambient authority.
