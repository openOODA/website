-- WHAT IT BRINGS --

01
OCAPS // Capability Security

Every effect — network, disk, process, GPU, display scanout — requires a capability token held by the code that performs it. Missing a cap isn't a warning — the build refuses. 26 substrate capabilities enforced at compile time and runtime.

02
LLVM IR // Self-Hosting Compiler

oodac compiles .oo source to LLVM IR and lets clang emit the native binary. The compiler is written in openOODA and compiles itself. Type-checks run in <3ms via Merkle-AST caching.

03
AGENT-NATIVE // Built for AI

The toolchain and OS ship native MCP servers, an LSP, and an llms.txt map — while keeping 1-binary-per-repo stationary topology (16–256 LOC per page) for autonomous agent verification.

04
NT + seL4 HYBRID KERNEL // Zero-Root OS

openOODA-kernel fuses Windows NT uniform executive object headers (`Ob`) with seL4 `CSpaceTable` slot capabilities and cascading `CdtTree` revocation, powering a zero-root `openOODA-OS` and Wayland `openOODA-DE`.

05
ASYMMETRIC PERFORMANCE // SMT & Zero-Copy Arenas

Compile-time SMT verification (QF_LIA) elides bounds checks, while 64-byte aligned bump arenas and lock-free actor channels operate without garbage collection pauses.

06
TWO-VIEW TAXONOMY // 5 Layers × 12 Categories

AI agents operate on flat 1-binary-per-repo git repositories across 5 GitHub Organizations, while humans browse a 5-Layer × 12-Category faceted catalog compiled directly from each repo's ooda.pkg manifest.
