OODA Value Score (OVS)_

oobench is the native .oo benchmark harness and agent evaluator for the openOODA ecosystem. Rather than ranking models on raw pass-rate alone or raw tokens/sec alone, oobench computes the OODA Value Score (OVS)—squaring verified gate quality while weighting token efficiency, wall-clock completion speed, and normalized cycle cost.
